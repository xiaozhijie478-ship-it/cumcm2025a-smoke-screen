本仓库是三人组内部的可复现工作区，保存 2025 年全国大学生数学建模竞赛 A 题的统一模型、Q1-Q5 求解代码、数值证据、正式结果表和交接材料。仓库默认为私有；未经全组同意不要改为公开。

4. Q1-Q5 各阶段总结：了解每一问的定义、算法和认证链。

## 全队唯一有效的观测定义

真目标是完整圆柱体。对任意时刻 `t` 和圆柱表面任一点 `P`，从导弹当前位置 `M(t)` 到 `P` 的有限线段必须与至少一颗有效烟雾球相交，才算该点被遮蔽。只有当圆柱表面全部点均满足此条件时，该时刻才计入有效遮蔽。

- 不得用目标中心替代完整圆柱表面。
- 不得用无限直线替代导弹到目标点的有限线段。
- 多球情形允许不同烟雾球分别覆盖不同目标区域，即采用 `对每个 P，至少存在一颗有效球` 的联合定义。
- 烟雾球半径为 10 m，起爆后有效 20 s，并以 3 m/s 匀速下沉。
- 主值采用 `g = 9.8 m/s²`，并保留 `9.78-9.82 m/s²` 敏感性分析。

## 快速开始

建议使用 Python 3.9；当前正式结果是在 `numpy 2.0.2`、`scipy 1.13.1` 环境下复核的。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m compileall -q .
python q1_strict_occlusion.py
python q2_optimize.py --help
python q3_optimize.py --help
python q4_optimize.py --help
python q5_optimize.py --help
```

完整优化和认证任务可能耗时较长。第一次接手时先运行快速检查并核对保存的 JSON/XLSX，不要直接覆盖正式证据文件。具体命令见 `docs/复现指南.md`。

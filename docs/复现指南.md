# 复现指南

## 1. 建议环境

- Windows 10/11 或常规 Linux 环境。
- Python 3.9 优先；Python 3.12 需要重新确认 SciPy/CVXPY 兼容性。
- 当前基线复核环境：Python 3.9.13、NumPy 2.0.2、SciPy 1.13.1。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## 2. 第一次克隆后的快速检查

```powershell
python -m compileall -q .
python -c "import numpy, scipy, cvxpy; print(numpy.__version__, scipy.__version__, cvxpy.__version__)"
python q1_strict_occlusion.py
python q2_optimize.py --help
python q3_optimize.py --help
python q4_optimize.py --help
python q5_optimize.py --help
```

如果上述检查失败，先处理环境，不要修改模型常量来“让程序跑起来”。

## 3. 计算入口

| 问题 | 主要入口 | 作用 |
|---|---|---|
| Q1 | `q1_strict_occlusion.py` | 严格几何、算法 B/C、题设参数结果 |
| Q2 | `q2_optimize.py` | 多起点搜索、局部精修和给定方案复核 |
| Q2 上界 | `q2_global_search.py` | 连续单段目标的全局搜索与锥松弛 |
| Q3 | `q3_optimize.py` | 三弹共享航迹、接力和联合目标 |
| Q3 审计 | `q3_global_audit.py`、`q3_upper_branch_bound.py`、`q3_upper_velocity_branch_bound.py`、`q3_velocity_domain_audit.py` | 全角域攻击、核心分支上界、贡献层分解与完整航向域分片认证 |
| Q4 | `q4_optimize.py`、`q4_synergy_search.py` | 三机累计目标与双球协同搜索 |
| Q4 上界 | `q4_independent_upper_certificate.py`、`q4_joint_structural_upper.py`、`q4_upper_branch_bound.py` | 主分支与联合结构上界 |
| Q5 | `q5_optimize.py` | 候选、组合、精修、验证和导出 |
| Q5 认证 | `q5_certify_joint.py` | 连续时间与连续圆柱表面夹逼 |

先运行 `--help` 确认参数。`--quick` 只用于烟雾测试，不能替代正式结果。

## 4. 建议复现顺序

1. Q1：确认几何底座和重力主值。
2. Q2：使用 `--quick` 做接口检查，再使用保存的正式参数回代。
3. Q3/Q4：先用 `--incumbent-only`、`--final-only` 或现有 JSON 做给定方案复核，再启动昂贵搜索。
4. Q5：先审计 `q5_*.json` 的候选与最终方案，再按 `--triads`、组合枚举、分块精修、验证和认证的顺序复跑。
5. 只有当数值与阶段总结一致后，才允许重新生成 `deliverables` 中的 Excel。

Q3 最新完整域拼接可直接检查：

```powershell
python q3_validate_certificate_manifest.py
```

它应重建原始上界 `11.450000000000122 s`，论文中向外写为 `11.451 s`。

## 5. 正式输出与证据

- `deliverables/result1.xlsx`：Q3 正式结果表。
- `deliverables/result2.xlsx`：Q4 正式结果表。
- `deliverables/result3.xlsx`：Q5 正式结果表。
- 根目录 `q1_*.json` 到 `q5_*.json`：搜索、验证、攻击和证书记录。
- `五问最新成果与独立评审_20260826.md`：结论边界的总索引。
- `Q3完整域分解与航向认证_20260829.md`：Q3 完整域 11.451 s 向外取整上界、两弹域 8.18 s 上界及剩余开放域。
- `q3_full_domain_certificate_manifest.json`：Q3 各贡献层的证据文件、航向覆盖和结论边界清单。

正式输出应保留：完整参数、随机种子、网格精度、终止条件、运行时间、环境版本和三位小数回代结果。

## 6. 回归检查

每次重构或模型修改后至少核对：

- Q1 时长 1.391642668 s；
- Q2 时长 4.588048258 s；
- Q3 时长 7.650405706 s；
- Q4 时长 11.735130825 s；
- Q5 `J_sum` 35.109171990 s；
- 投放间隔、起爆高度、有效期和舍入回代均可行；
- 多球联合定义仍是 `对每个目标点至少存在一颗球`，而不是单球时长简单相加。

数值差异若落在已知评价区间内，应记录原因；若超过评价区间，必须停止覆盖正式结果并进行定位。

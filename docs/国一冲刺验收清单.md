# CUMCM 2025 A 国一冲刺验收清单

版本：2026-08-26  
用途：安泰队友完成 coding、数院队友完成建模后，由你逐项反查。  
原则：先排除一票否决，再检查模型正确性，最后才看数值是否还能提高。

## 0. 使用方法

每项只允许标记三种状态：

- `[绿]` 已提交可打开的证据，另一位成员复核通过。
- `[黄]` 有口头说明或部分文件，但不能独立复核。
- `[红]` 缺失、矛盾、无法运行，或者结论强度超过证据。

冻结论文的最低条件：

- 所有 P0 项必须为绿；
- P1 项至少 80% 为绿，其余只能为黄，不能有红；
- Q1-Q5 的正式数字、Excel、图表和正文必须完全一致；
- 任一人无法解释“有效遮蔽定义”和“给定方案评价区间与优化上界的区别”，不得冻结。

## P0-2. 全文唯一观测定义：绝不能换口径

- [ ] 把算法 C 的分段极值求解与上述几何命题对应起来。

## P0-4. 每个“最优、上界、认证”必须标明适用域

### 全文统一使用四级证据

1. 给定策略的可行目标值；
2. 给定策略真实目标值的数值评价区间；
3. 明确分支或受限参数域的优化上界；
4. 完整物理参数域的优化上界。

### 你要检查什么

- [ ] 所有“认证区间”都注明认证的是给定方案评价值，还是优化问题最优值。
- [ ] 所有“上界”都列出固定了哪些变量、覆盖哪些变量、依赖哪些假设。
- [ ] 元启发式单次最好值只称“可行解”或“当前最好可行解”。
- [ ] Q3 的 3.16% 只写成核心活跃分支间隙，不能写成完整八维全局间隙。
- [ ] Q4 的 0.8774% 只属于单球完整遮蔽主分支；25.878 s 结构界仍依赖连通性假设。
- [ ] Q5 的 `[35.067366178, 35.112385634] s` 只认证当前方案的真实 `J_sum`，不是全局最优区间。

### 你反问队友

1. 这个区间的上下端包住的是“当前点”还是“所有可行点中的最优点”？
2. 这个上界固定了哪些变量？若解除固定还成立吗？
3. 证书依赖单球有效时间集合连通吗？若连通性失败，哪条结论失效？

## P1-1. 验证体系必须围绕主张

### 每问最低验证包

- [ ] 可行性：逐条给出约束余量，而不是只写“均满足约束”。
- [ ] 正确性：手算、解析极限、小规模精确检查或独立算法。
- [ ] 数值收敛：时间步长、圆周采样、圆柱表面采样和求解容差变化。
- [ ] 算法稳定性：多随机种子、运行时间和终止状态分布。
- [ ] 比较：与简单基线或旧方案在同一口径、同一预算下比较。
- [ ] 消融：删除联合覆盖、跨导弹复用、空槽激活、分块精修等模块后目标如何变化。
- [ ] 敏感性：`g`、舍入、关键接受阈值和可能的边界参数。
- [ ] 失败情景：主动展示至少一个模型可能失效或结论变弱的情形。

## P1-2. 国一价值必须浓缩为 3-4 个创新点

建议只保留以下四个，避免把常规优化器包装成创新：

1. **严格观测量创新**：完整圆柱表面、有限视线段和 `∀P∃i` 多球联合遮蔽。
2. **几何降维创新**：利用阴影集合凸性，将完整圆柱验证化为上下边缘圆周最坏点问题。
3. **优化证据创新**：把启发式搜索与独立评价、参数盒上界、保护量认证组合，明确区分可行值与最优性证据。
4. **Q5 资源复用创新**：同一无人机航线跨导弹复用烟雾弹，并用联合新增时长、留一消融和多目标权衡验证收益。

每个创新都必须写成：原缺陷—数学改动—量化收益—计算代价—适用边界。

### 你反问队友

- 不使用该创新，基线会错在哪里或损失多少？
- 哪个消融或对照证明收益来自该创新？
- 创新增加了什么计算或解释成本？
- 在什么情况下该创新不成立？

## P1-3. 论文结构与信息密度

### 摘要

- [ ] 一页以内；包含目标、核心方法、Q1-Q5 关键结果、验证和结论边界。
- [ ] 不堆算法名，至少解释一个最关键的模型选择理由。
- [ ] Q3-Q5 使用“当前最好可行解/分支近优”等准确措辞。
- [ ] 不在摘要中直接比较不同 Q5 目标口径。

### 正文

- [ ] 不设目录；正文页数满足当年规则。
- [ ] 前 3-5 页让评委看懂统一观测量、模型链和创新点。
- [ ] 每问按“新增结构—模型—求解—结果—验证—边界”组织。
- [ ] 搜索参数、长日志和大量证书细节放附录，正文只保留支撑核心主张的证据。
- [ ] 五问不是平均分配篇幅；Q1 几何底座、Q2 可信度样板、Q5 综合创新应占核心位置。

### 图表

- [ ] 一张图只回答一个问题，图注写明对象、单位、时间范围和数据来源。
- [ ] 结果表包含正式值、评价区间/上界、基线和结论边界。
- [ ] 有效数字与认证精度匹配，不用九位小数制造虚假精确感。
- [ ] 正文表格中的所有数字都能由 JSON/XLSX 或脚本输出追溯。

### 模型评价

- [ ] 优点不是“精度高、通用性强”等空话，而是对应严格几何、联合覆盖、上界和复现证据。
- [ ] 局限主动写 Q3/Q4 完整域界较松、Q5 无全局优化上界和连通性未解析证明。
- [ ] 推广写清需修改的目标几何、烟雾模型、运动学参数和传感/遮挡定义。

## P1-5. 模拟评委攻击

冻结前，由三个人分别扮演不同评委：

### 数学评委攻击

- 圆柱降维证明是否完整？
- 必要条件是否被写成充分条件？
- 分支上界是否被冒充全局上界？

### 算法评委攻击

- 换随机种子是否还能得到相近方案？
- 时间/空间网格变细是否收敛？
- 代码能否从空环境运行？
- Q5 九次运行是否真的全部留痕？

- 只看摘要、图和结论，能否说出本文的三个核心贡献？
- 5 分钟内能否找到每问答案和验证？
- 是否被大量参数、日志和小数淹没？
- 哪句话最可能让评委怀疑夸大或口径错误？

只有三类攻击都没有红项，才进入最终排版。
